Terms of Service

Updated

Description: a 3rd party web app utilising market data and limited level user information to calculate investment values and plan investment portfolio pathways which stores key or data only in the user's browser. To reduce API requests required the 3rd party website tornsy.com is utilised for retrieving live stock market data.

The Scripts page reads public listing data from greasyfork.org so each script shows its current version and dates. Nothing about you is sent with those requests. Editing that page, which only the developer can do, writes to github.com using the developer's own access token.

Feedback and incident reporting forms are handled through a private discord.com server accessible only by the developer. API keys are scrubbed from all reports, however user ID is included for follow up communication.

ToS: You maintain full control of your data; everything is stored in your browser. No data is sent anywhere.
